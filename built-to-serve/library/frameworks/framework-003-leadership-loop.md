# FRAMEWORK 003 — The Leadership Loop

> Herramienta, no principio. Cómo se aplica una verdad.

- **Canon:** Framework 003
- **Qué es:** Un ciclo, no una línea: Servir → Confianza → Influencia → (vuelve a) Servir.
- **Estado:** Por diseñar

_(Gráfico por diseñar.)_

## Descripción

El liderazgo no es una escalera que se sube una vez. Es un ciclo que se gana cada día: sirves, ganas confianza, esa confianza te da influencia, y la influencia se usa para servir mejor. DISEÑO: diagrama circular a mano (4 nodos en círculo con flechas curvas).
