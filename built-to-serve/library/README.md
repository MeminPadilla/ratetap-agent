# The Library

The content itself, sorted into the five parts of the
[Content Hierarchy](../03-CONTENT-HIERARCHY.md).

- `part-1-foundations/` — Purpose, Identity, Leadership, Service, Hospitality, Culture
- `part-2-four-pillars/` — Hospitality, Mentality, Professionalism, Discipline
- `part-3-leadership/` — Coaching, Feedback, Hiring, Culture, Communication, Trust, Ownership, Conflict
- `part-4-operations/` — Service, Standards, Training, Fine Dining, Guest Experience, Systems, Execution
- `part-5-personal-growth/` — Habits, Mindset, Purpose, Character, Discipline

To add a piece: copy [`../templates/article-template.md`](../templates/article-template.md),
fill the framework, pass the seven gates, and file it in the part it belongs to.
