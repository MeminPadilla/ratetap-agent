# Built to Serve

> We don't build restaurants. We build people.
> People build culture. Culture builds extraordinary businesses.

This is not a folder of posts.

This is an intellectual property — a leadership philosophy being built one
principle at a time. Everything here belongs to the same book: the
**Built to Serve Leadership Bible**.

---

## What this system is

A structure that protects one worldview and lets it grow without drifting.

Every article, framework, keynote, workshop, and chapter is filed into the
same hierarchy, written in the same voice, and measured against the same
standards. Nothing exists alone.

## The library

[`library/`](library/) holds the content itself, sorted into the five parts.
Every finished piece lives in the part it belongs to. If a piece doesn't have
a home here, it doesn't have a reason to exist yet.

## How to create

1. Start from [`templates/article-template.md`](templates/article-template.md).
2. Fill in the framework — Purpose, Pillar, Principle, Lesson, Framework,
   Quote, Takeaway.
3. Run it through the Archivist's standards in
   [`05-THE-ARCHIVIST.md`](05-THE-ARCHIVIST.md).
4. If it survives, file it in the right `library/part-*` folder.
5. If it doesn't, it doesn't get published. We improve it or we reject it.

## The one rule above all others

Protect the philosophy above everything else.
